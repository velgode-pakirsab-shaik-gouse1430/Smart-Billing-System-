# SmartBill POS - Total Website Billing & Inventory System

A complete, responsive Point of Sale (POS), billing, and inventory tracking web application built using modern **HTML5**, **CSS3**, and **JavaScript (ES6+)**.

---

## 🚀 Key Features & System Capabilities

| Feature | Details & Workflow |
| :--- | :--- |
| **Indian Rupees (₹) & GST Split (CGST + SGST)** | Fully localized to **Indian Rupees (₹)** with standard Indian number formatting (`₹1,25,000.00`). Complies with Indian tax invoicing by calculating and displaying the **CGST** and **SGST** 50/50 breakdown (e.g. 18% GST = 9% CGST + 9% SGST). |
| **Dual Print Layouts: Thermal Slip (80mm) & A4 Tax Invoice** | Toggle between a compact **Thermal POS Receipt (80mm)** and a formal **A4 GST Tax Invoice** (with HSN codes, party details, tax breakdown, and authorized signatory box). |
| **Quick Barcode / SKU Scanner Input** | Scan any barcode with a handheld scanner or type an SKU (e.g., `SKU-1001`) in the top scanner box and hit `Enter` to instantly add the product to the active bill with scanner audio feedback. |
| **Keyboard Shortcuts for Rapid Billing** | Cashiers can operate with hotkeys: `F2` (Search Products), `F4` (Focus Barcode/SKU Scanner), `F8` (Complete Sale / Checkout), `F9` (Add Product), and `Esc` (Close Dialogs). |
| **Audio Scanner Feedback (Web Audio API)** | Crisp POS scanner beeps on item additions and pleasant completion chimes on checkout (synthesized via browser Web Audio API; toggleable via the **🔔 Sound** button in the header). |
| **Add Units to Out-of-Stock Products (Restock)** | When any product runs out of stock (`0 left`), its card transforms to show an amber **"📦 Out of Stock • Add Units"** button. Clicking it opens a restocking modal with quick preset chips (`+5`, `+10`, `+25`, `+50`, `+100`) and live stock preview. Products can also be replenished anytime via the **"+ Stock"** button. |
| **Add & Edit Products with Images & Pricing** | Add new products or click the **`✏️` Edit** icon on existing products to modify name, category, unit price (₹), SKU, HSN tax code, stock, or image (via file upload or image URL). |
| **Add Product Button with Increment & Decrement** | Each product card features a dynamic **"Add to Bill"** button. In the active bill/cart, each item includes interactive **`[+]` Increment** and **`[-]` Decrement** stepper buttons with boundary validation. |
| **Count No. of Products Sold and Left** | Live, reactive tracking of **Products Sold** and **Products Left** across multiple places:<br>• Top metrics dashboard (Global count)<br>• Product card badges (e.g. `Low: 5 left`, `28 Sold`)<br>• Per-item stock remaining alert inside active bill (`Left after bill: X units`)<br>• Real-time stock deduction upon bill checkout. |
| **Show Total on Each Product** | **Line item total** displayed in real-time in the bill (`Qty × Unit Price = ₹Total`). In addition, the **"Product Totals & Stock"** modal and product card `ℹ️` button show the exact lifetime earnings / revenue generated by each product (`Sold × Price`). |
| **Dynamic UPI QR Code (GPay, PhonePe, Paytm)** | When selecting "Online / UPI" payment method, an instant NPCI-compliant UPI QR code is generated with the exact bill total in Indian Rupees (₹) and store VPA/UPI ID. Customers can simply point and scan with any UPI app to pay. |
| **Parked Bills / Multi-Cart Hold System** | When a customer needs to fetch more items or steps away, click **"Hold"** to park their cart and free up the billing counter. Click **"⏸️ Parked Bills"** to view, resume, or discard any held cart anytime. |
| **WhatsApp Digital Invoice Sharing** | Send a customer their itemized GST bill via WhatsApp with one click (`📲 Share WhatsApp`). Pre-formats the store details, line items, CGST/SGST taxes, and grand total into a neat message. |
| **Cash Tender & Change Return Calculator** | When selecting "Cash" payment, the cashier can enter the **Cash Tendered (₹)** amount given by the customer. The system automatically computes and highlights the exact **Change to Return (₹)**. |
| **Past Invoices & Sales Ledger** | Click **"📑 Past Invoices"** in the header to view a historical ledger of all previous customer orders with search/filter and a **"🖨️ View / Print"** button to re-print any receipt. |
| **Store Profile & GST Customization** | Click **"⚙️ Store Info"** in the header to set your Store Name, Tagline, Address, Phone, GSTIN number, and UPI ID. These details automatically appear on all generated customer invoices, UPI QR codes, and receipts. |
| **CSV Data Export** | One-click export for **Inventory Report (CSV)** and **Sales History (CSV)** for bookkeeping, audits, or GST records. |
| **Offline Persistence** | Uses `localStorage` to retain all added products, updated stock counts, sales history, parked bills, store profile, and invoice counters across page reloads. |

## ⌨️ Cashier Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>F2</kbd> or <kbd>/</kbd> | Focus product search bar |
| <kbd>F4</kbd> | Focus quick Barcode / SKU scanner input |
| <kbd>F8</kbd> | Complete sale & print bill (Checkout) |
| <kbd>F9</kbd> | Open "+ Add New Product" modal |
| <kbd>Esc</kbd> | Close active modal dialog |
